# Collabute X TheBlock. Hackathon — Team Plan

**Date:** Sunday, 30 August · 10:00 AM – 6:00 PM
**Location:** TheBlock. Street, One Central, Dubai World Trade Centre, Dubai
**Event page:** https://luma.com/theblock-2ej8

## The Challenge

Build an **original AI-powered product that solves a real problem** — built *during* the event (no pre-built products). No fixed industry theme; suggested areas include developer tools, AI agents, productivity, fintech, education, collaboration, consumer apps, creative tools, and social impact.

## Mandatory Tech Stack (all three, meaningfully integrated)

- [ ] **Devin by Cognition** — AI-assisted development
- [ ] **Convex** — backend / database / infrastructure
- [ ] **Context.dev** — context system

> Superficial use (installing SDKs, logo mentions) = disqualification from prizes. Each tech must directly contribute to the product, and the team must be able to explain how.

## Key Rules

- Team size: **1–4 people**, one team per person; no member changes after start without approval
- All core functionality built during the event (scaffolding/dev environment prep beforehand is OK)
- Additional APIs/frameworks/models allowed, but can't replace the three required techs
- Must disclose any major pre-existing components
- AI tools encouraged, but the team must understand and be able to operate/explain everything
- Use test/synthetic data; no confidential or unlawfully obtained data
- **Submission deadline: 5:00 PM — STRICT** (via official form shared at opening session)
